# ভয়েস অ্যালার্ট (Android)

## GitHub থেকে APK বানানোর নিয়ম
1. GitHub-এ নতুন repository খুলুন এবং এই ফোল্ডারের সব ফাইল (লুকানো `.github` সহ) আপলোড করুন।
2. Repository-র **Actions** ট্যাবে যান → **Build APK** → **Run workflow** (push করলে নিজে থেকেই চলবে)।
3. বিল্ড শেষ হলে ওই run-এর নিচে **Artifacts → VoiceAlert-APK** ডাউনলোড করুন, জিপ খুলে `app-debug.apk` ফোনে ইনস্টল করুন।

## ব্যবহার
- অ্যাপ খুলে পারমিশন দিন, "ভয়েস সেবা চালু" রাখুন।
- প্রতিটি ইভেন্টে লেখা বদলানো, নিজের অডিও ফাইল বাছাই, শুনে দেখা ও রিসেট করা যায়।
